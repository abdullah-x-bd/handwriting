# Hand Magic Future Reference Preset

This file records the exact settings behind the approved readable full-page sample generated by `readable_fullpage_sample.py`.

## Status

**Use this as the default Hand Magic preset for future handwriting generation.**

Reference output: `HandMagic_A1_Legibility_Fixed`

## Model

- Upstream: `OmarMusayev/ai-handwriting-generator`
- Model path: `weights/lstm.pt`
- Generation function: `generate_conditional_sequence`
- Generation mode: `prime=True`
- Device used for the reference run: CPU

## Handwriting style

- Primary Hand Magic style index: `2808`
- Fallback Hand Magic style index: `1021`
- Bias: `24.0`
- Style source: Hand Magic's bundled `data/strokes.npy` and `data/sentences.txt`
- The fallback is used only when the primary writer produces a collapsed or unstable line.

## Page geometry

- Page: A4 portrait
- Raster size: `2480 x 3508`
- Left edge: `150`
- Right edge: `2330`
- Top edge: `145`
- Bottom limit: `3430`
- Ink RGB: `(22, 55, 123)`
- Background RGB: `(255, 255, 253)`
- Stroke width: `3`
- Final Gaussian blur: `0.02`

## Text layout

- Target line length: `55` characters
- Balanced-line maximum: `62` characters
- Lines are balanced with dynamic programming to avoid tiny final fragments.
- The answer heading is omitted from the handwriting page when a separator page already gives the answer number.
- Short equations of up to 65 characters are kept as a single line.

## Critical width rule

**Never horizontally stretch Hand Magic strokes independently.**

The approved sample preserves the native handwriting aspect ratio.

For each generated line:

```python
scale = ((RIGHT - LEFT) * 0.95) / native_line_width
```

The same scale is applied to both x and y. The line therefore occupies about 95 percent of the writing width without deforming the letters.

If a line does not naturally fill the page, make the text line longer through balanced wrapping. Do not distort the handwriting.

## Generation quality control

### Primary writer

- Maximum attempts per line: `10`
- Seeds:

```text
20260929 + line_index * 1009 + attempt * 7919
```

- Stop retrying after at least 3 attempts when the best score is `<= 12.0`.
- If the best primary score is `> 22.0`, try the fallback writer.

### Fallback writer

- Style index: `1021`
- Maximum attempts: `8`
- Seeds:

```text
60260929 + line_index * 1301 + attempt * 6151
```

- Stop retrying after at least 3 attempts when the best score is `<= 12.0`.
- If both writers remain above `22.0`, fail the line rather than accepting an illegible scribble.

## Candidate quality score

The accepted implementation scores every generated line using:

- EOS failure penalty: `+100`
- Target generated-sequence length ratio: `16.0` steps per input character
- Sequence-ratio penalty multiplier: `0.7`
- Minimum pen-lift / word ratio: `1.1`
- Low pen-lift penalty multiplier: `30.0`
- Aspect ratio below `3.0`: `+25`
- Aspect ratio above `45.0`: `+15`

This scoring is designed to reject classic Hand Magic failures such as one long flourish, premature collapse, runaway output, or missing pen lifts.

## Vertical page fill

- Paragraph gap: `24`
- Per-line minimum rendered height contribution: `72`
- Base gap after each line: `18`
- Remaining page height is redistributed across line gaps.
- Additional distributed gap is capped at `32`.

This is what fixes the earlier half-empty-page problem while keeping the handwriting proportions intact.

## Text normalization

Before generation:

- typographic quotes are converted to ASCII quotes
- dashes are normalized
- `π` becomes `pi`
- Unicode is normalized to ASCII where possible
- unsupported symbols are replaced or converted to simple word forms
- whitespace is collapsed

## Legacy constants currently present in the reference script

The reference script still defines:

- `TARGET_H = 90`
- `LINE_STEP = 120`
- `CANDIDATES = 3`

The final approved renderer no longer uses those constants to size or space the lines. The active sizing logic is the aspect-ratio-preserving 95 percent width scale plus dynamic vertical spacing described above.
